Importar estudiantes desde CSV

Sube un archivo CSV para registrar o actualizar varios estudiantes de una sola vez.

Volver
Usa un archivo CSV en formato UTF-8.
Cancelar
Formato esperado

El archivo debe tener este orden de columnas:

nombres,apellidos,anio,tipoBachillerato,seccion

Ejemplo:

nombres,apellidos,anio,tipoBachillerato,seccion
Juan Carlos,Pérez López,PRIMERO,BACHILLERATO_GENERAL,A
María Fernanda,Hernández Ruiz,SEGUNDO,ADMINISTRATIVO_CONTABLE,B
Luis Alfredo,Castro Mejía,TERCERO,INFRAESTRUCTURA_TECNOLOGICA_Y_SERVICIOS_INFORMATICOS,C
Si un estudiante ya existe con la misma combinación de nombres, apellidos, año, tipo de bachillerato y sección, el sistema actualizará ese registro en lugar de duplicarlo.
Valores permitidos
Año
  • PRIMERO
  • SEGUNDO
  • TERCERO
  • 1ro, 2do, 3ro
  • 1, 2, 3
Tipo de bachillerato
  • BACHILLERATO_GENERAL o General
  • TECNICO_PRODUCTIVO_EN_SALUD_Y_BIENESTAR_SOCIAL o Salud
  • ADMINISTRATIVO_CONTABLE o Contable
  • INFRAESTRUCTURA_TECNOLOGICA_Y_SERVICIOS_INFORMATICOS o Informatica
